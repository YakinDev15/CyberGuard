# CyberGuard – Passwort-Sicherheitsprüfung

## Projektbeschreibung

CyberGuard ist ein webbasiertes Tool zur Überprüfung der Passwortstärke.

## Verwendete Technologien

- HTML
- CSS
- JavaScript
- XAMPP Lite (lokale Entwicklungsumgebung)

## Funktionen

- Echtzeit-Analyse der Passwortstärke
- Anzeige der Passwortstärke in Prozent
- Überprüfung von fünf Sicherheitsanforderungen
- Passwort anzeigen und verbergen
- Visuelle Anzeige der Sicherheitsstufe

## Projektziel

Ziel dieses Projekts ist es, die Grundlagen der Webentwicklung praktisch anzuwenden und ein besseres Verständnis für Passwortsicherheit zu entwickeln.

## Lokale Installation und Start

1. XAMPP Lite installieren und Apache starten.
2. Den Projektordner in das Verzeichnis `www` kopieren.
3. Den Browser öffnen.
4. Folgende Adresse eingeben:

   `http://localhost/password-security-checker/`

5. Das Projekt wird im Browser geöffnet.
